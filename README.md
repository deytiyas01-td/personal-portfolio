# 👨‍💻 Personal Portfolio Landing Page

A responsive personal developer portfolio website designed to showcase my **bio, technical skills, projects, and social links** in a clean and modern layout.

## ✨ Features

- Semantic HTML5 structure
- Responsive design for desktop, tablet, and mobile
- CSS Flexbox and Grid layouts
- About Me section
- Technical Skills section
- Projects showcase
- Social media and GitHub links
- Clean and modern UI

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **Flexbox**
- **CSS Grid**

## 📁 Project Structure

```text
personal-portfolio/
├── index.html
├── style.css
└── README.md
```
